# Archived project material

Moved here during the folder cleanup on 9 September 2026. These files are retained
for reference and recovery; the application and test suite do not depend on them.

- `legacy_scripts/`: seven former root-level migration and diagnostic scripts.
  The historical source-rewriting migrations remain disabled.
- `diagnostics/`: two old test images and three intermediate audit logs.
- `patches/my_review_diff.patch`: the existing historical patch, preserved without
  applying it.

Current code is in `can_relax/`, automated tests are in `tests/`, and the current
audit report and final evidence are in `shared_review/`. Reference PDFs remain in
`References/`. The installed environment remains in `.venv/`.

Python and pytest caches were deleted because they regenerate automatically.
The empty `models/` directory was removed. No experimental data was deleted.
